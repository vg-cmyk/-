# CineLingua - Desktop Application

Приложение для изучения английского языка через фильмы и сериалы.

## Запуск в режиме разработки

```bash
npm install
npm start
```

## Сборка исполняемого файла

### Windows
```bash
npm run build:win
```

### macOS
```bash
npm run build:mac
```

### Linux
```bash
npm run build:linux
```

## Структура проекта

- `main.js` - главный процесс Electron
- `preload.js` - мост безопасности
- `index.html` - интерфейс приложения
